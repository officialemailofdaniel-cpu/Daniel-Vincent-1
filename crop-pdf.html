How to use Crop PDF

Adjust the visible page area by reducing margins, which can be useful for scanned pages with excess whitespace.

What to know before you start

Cropping applies a crop box; it does not securely erase hidden content. Review the output and do not use cropping as a substitute for redacting confidential information.

Frequently asked questions

Can I crop pages differently?

The current tool applies the same percentage setting to all pages.

Does cropping erase hidden content?

No. A crop box changes the visible area and should not be treated as secure redaction.

Keep your original document until you have checked the downloaded result. File size, browser memory and document structure can affect processing. Do not use a PDF crop or watermark as a substitute for secure redaction of confidential information.
