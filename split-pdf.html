How to use Split PDF

Create a smaller PDF containing selected pages. Enter page numbers or ranges such as 1-3,5 in the page field.

What to know before you start

Page numbers refer to the original PDF order. Check the range and open the downloaded file to verify that it contains the pages you intended.

Frequently asked questions

What page format should I enter?

Use comma-separated page numbers and ranges with a hyphen, for example 1-3,5.

Does splitting delete my original?

No. The original file on your device remains unchanged.

Keep your original document until you have checked the downloaded result. File size, browser memory and document structure can affect processing. Do not use a PDF crop or watermark as a substitute for secure redaction of confidential information.
