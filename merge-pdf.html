What to know before you start

The tool copies pages from each selected PDF into a new document. Password-protected, damaged or unusual PDFs may fail. Review the downloaded file before sharing it.

Frequently asked questions

How many files can I merge?

Select two or more PDF files; practical limits depend on device memory and file sizes.

Will the original PDFs be changed?

No. The tool creates a separate output file and does not overwrite the originals.

Keep your original document until you have checked the downloaded result. File size, browser memory and document structure can affect processing. Do not use a PDF crop or watermark as a substitute for secure redaction of confidential information.
