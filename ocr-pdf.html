How to use OCR PDF

OCR attempts to recognize letters in page images and return text, which can help with scanned documents that do not have selectable text.

What to know before you start

Accuracy depends on scan resolution, contrast, language and orientation. Review names, numbers and important details. The current OCR engine is configured for English.

Frequently asked questions

Can OCR read a scanned document?

It attempts to recognize text by rendering scanned pages as images.

Will the result be perfect?

No. OCR can make mistakes, so proofread the extracted text.

Keep your original document until you have checked the downloaded result. File size, browser memory and document structure can affect processing. Do not use a PDF crop or watermark as a substitute for secure redaction of confidential information.
